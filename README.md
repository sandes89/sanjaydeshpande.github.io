# Dr. Sanjay Deshpande — Personal Website

A static, responsive academic portfolio for GitHub Pages. The site uses plain HTML, CSS, and JavaScript; there is no build step.

For detailed first-time setup, local Git commands, future content updates, and troubleshooting, see [REPOSITORY-GUIDE.md](REPOSITORY-GUIDE.md).

## Publish with GitHub Pages

1. Create a public repository named `sanjaydeshpande.github.io` under the GitHub account `sanjaydeshpande`.
2. Add the contents of this folder to the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
4. The workflow in `.github/workflows/pages.yml` deploys the site on pushes to `main`. Once the workflow succeeds, it will be available at <https://sanjaydeshpande.github.io/>.

## Update content

- Edit the profile and publication content in `index.html`.
- Edit layout and styling in `styles.css`.
- `script.js` only enhances the mobile navigation; the main content works without JavaScript.

The page links to the supplied LinkedIn and Google Scholar profiles. Publication and biography details are based on the supplied CV.
